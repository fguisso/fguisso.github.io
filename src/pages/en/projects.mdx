Git Pages is my favorite way to host static web apps without spinning up complex infrastructure. Deploys are just a git push, hosting stays free for open source projects, and the CDN keeps content close to whoever visits.

Everything currently lives on GitHub Pages, but I’m preparing a disaster-recovery setup that mirrors the same artifacts on GitLab Pages. The more layers I have, the easier it is to experiment in the lab without worrying about downtime.

To take advantage of this approach each app must be 100% client-side, using modern browser APIs. If a project needs a dedicated backend, I publish it through a different stack. Git Pages plays the role of a fast showcase.

## Tools and homelab

- [Homelab](https://wiki.guisso.dev/linux/homelab/) - My Proxmox setup, the services I run, and notes on automating them.
- [Pipa](https://github.com/fguisso/pipa) - I run it in my homelab to host static sites and share previews.
- [sfer.nvim](https://github.com/fguisso/sfer.nvim) - A Neovim plugin for reading SARIF reports in the editor.
- [bashingse](https://github.com/fguisso/bashingse) - Scripts for setting up Debian desktops and containers.
- [Gube](https://guisso.dev/gube/) - A 3D editor and visualizer for 2×2 and 3×3 Rubik's Cube algorithms. [Source on GitHub](https://github.com/fguisso/gube).
- [SunCVE](https://github.com/sunsecrn/suncve) - A dashboard by [Sunsec](https://web.archive.org/web/20250915150619/https://sunsec.net/posts/ "Sunsec blog archive") that brings together CVE records and security advisories. You can search by product, filter by severity, and find references to fixes.
- [Sun Net Tool](https://github.com/sunsecrn/sun-net-tool) - A [Sunsec](https://web.archive.org/web/20250915150619/https://sunsec.net/posts/ "Sunsec blog archive") Android app for learning about Wi-Fi diagnostics on authorized networks.
- [Dojo Shield](https://github.com/topics/dojo-shield) - Projects and exercises for secure development workshops.
- [MASS](https://guisso.dev/mass/) - A scorecard for assessing application security practices.
- [TPRM](https://guisso.dev/tprm/) - An interactive checklist for assessing vendor security maturity.
