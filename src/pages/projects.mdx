O Git Pages é hoje minha solução preferida para hospedar aplicações web estáticas sem depender de infraestrutura complexa. O deploy vira um push, o custo segue zero para projetos open source e o conteúdo fica distribuído pertinho de quem acessa.

Atualmente tudo vive no GitHub Pages, mas já estou preparando um plano de disaster recovery replicando os mesmos artefatos no GitLab Pages. Quanto mais camadas, mais tranquilo fico para testar coisas diferentes no laboratório.

Para aproveitar essa abordagem é essencial que cada aplicação seja 100% client-side, usando as APIs modernas do navegador. Quando o projeto depende de backend dedicado eu compartilho em outra stack; o Git Pages entra como vitrine rápida.

## Ferramentas e homelab

- [Homelab](https://wiki.guisso.dev/linux/homelab/) - Minha infraestrutura com Proxmox, os serviços que mantenho e as anotações de automação.
- [Pipa](https://github.com/fguisso/pipa) - Hospedagem própria de sites estáticos. Uso no homelab para publicar e compartilhar prévias.
- [sfer.nvim](https://github.com/fguisso/sfer.nvim) - Plugin do Neovim para ler relatórios SARIF no editor.
- [bashingse](https://github.com/fguisso/bashingse) - Scripts para configurar desktops e contêineres Debian.
- [Gube](https://guisso.dev/gube/) - Editor e visualizador 3D de algoritmos de cubo mágico para cubos 2×2 e 3×3. [Código no GitHub](https://github.com/fguisso/gube).
- [SunCVE](https://github.com/sunsecrn/suncve) - Painel da [Sunsec](https://web.archive.org/web/20250915150619/https://sunsec.net/posts/ "Arquivo do blog da Sunsec") que reúne registros de CVEs e avisos de segurança. Dá para buscar por produto, filtrar por severidade e consultar referências para correções.
- [Sun Net Tool](https://github.com/sunsecrn/sun-net-tool) - Aplicativo Android da [Sunsec](https://web.archive.org/web/20250915150619/https://sunsec.net/posts/ "Arquivo do blog da Sunsec") para estudar diagnóstico de redes Wi-Fi em ambientes autorizados.
- [Dojo Shield](https://github.com/topics/dojo-shield) - Projetos e exercícios para workshops de desenvolvimento seguro.
- [MASS](https://guisso.dev/mass/) - Scorecard para avaliar práticas de segurança de aplicações.
- [TPRM](https://guisso.dev/tprm/) - Checklist interativo para avaliar a maturidade de segurança de fornecedores.
